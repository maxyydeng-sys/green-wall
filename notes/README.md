# 每日学习输入

线上日报只读取你主动放进本仓库的 `notes/YYYY-MM-DD.md`，不会读取电脑上的 Obsidian、聊天记录或其他本地目录。

创建当天笔记：

```sh
./green-wall note
```

填写文件后提交并推送到 GitHub。也可直接在 GitHub 网页创建或编辑当天文件。线上定时任务只能读取已推送的内容。

格式示例（替换为你的真实笔记）：

```markdown
# 2026-10-30

## 学习笔记

- 今天确认的知识、实践过程与原始链接。

## 知识卡片

Q: 今天学到的问题是什么？
A: 经过确认的答案与适用条件。

## 待办

- [x] 已完成的事项
- [ ] 后续需要完成的事项
```

知识卡片只提取代码块之外、单行 `Q:` 后跟 `A:` 的明确问答；待办从 Markdown 复选框统计。系统不会补写未经提供的学习经历或答案。正文展示上限 12000 字符，卡片展示最多 20 张，完整原文始终保留在来源文件。

本仓库公开，放入这里并推送的笔记也会公开。仅提交你希望公开的内容。

运行 `./green-wall preview` 查看当天完整日报。当天记录一旦生成就不会改写；后补的笔记仍保留在这里，可单独预览，但不会覆盖已生成的日报。
